WORKINGHOURS v2
================
This is a standalone local version of the WorkingHours tracker.

Features:
- START begins a live timer.
- FINISH stops it and automatically saves today's worked time.
- Daily history with manual editing.
- Local storage on the phone.
- Export/import backup.

QUICK TEST:
Open index.html in Chrome. Press START, wait a few seconds, then FINISH.
Your record will appear under Daily data.

IMPORTANT:
For a permanent home-screen PWA installation, these files need to be served from a secure web address (HTTPS).
If you open index.html directly as a local file, the app still works and stores data locally, but Chrome may not offer the normal PWA installation option.
